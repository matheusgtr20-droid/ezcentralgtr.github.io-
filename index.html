SOBRE O PROJETO

Feito para evoluir por versões.

O EzCentralGTR é um projeto independente para Android. A ideia é melhorar a centralização de ferramentas e a experiência de uso com atualizações progressivas, testes e documentação clara.

Desenvolvimento

Novas versões podem incluir mudanças visuais, correções e recursos. Antes de marcar uma versão como estável, é importante testar instalação, fluxos principais e permissões.

DÚVIDAS FREQUENTES

Antes de instalar.

O aplicativo já está pronto?

O projeto compilou, mas isso sozinho não comprova que todos os recursos funcionam. O lançamento deve ser marcado como disponível depois dos testes.

Por que o Android pode pedir permissões?

Alguns recursos dependem de permissões específicas. Leia o que cada permissão permite e conceda apenas as necessárias para as funções que pretende usar.

Como saber o que mudou?

As publicações devem incluir notas de versão com novidades, correções e limitações conhecidas.
